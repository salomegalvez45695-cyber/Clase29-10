Aplicación Dessert Clicker
=====================

Código para el Codelab de Conceptos Básicos de Android con Compose.

Introducción
------------

Dessert Clicker es un juego sobre cómo hacer postres.

Presiona el botón, haz un postre y gana mucho dinero.

Usa esta aplicación en el curso para explorar el ciclo de vida de Android y registrar mensajes en la consola de Android (Logcat).

Requisitos previos
------------------

Necesitas saber:
- Cómo abrir, compilar y ejecutar aplicaciones con Android Studio.
- Qué es una actividad y cómo crear una en tu aplicación.
- Qué hace el método onCreate() de la actividad y el tipo de operaciones que se realizan en ese método.
